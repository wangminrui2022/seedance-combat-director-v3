# Combat Patterns — 通用战斗结构库

这些是编排方法，不是固定模板。只选择当前任务需要的模块。

## 1. Grounded Duel — 写实单挑

目标：接触可信、空间清楚、双方都有攻防。

关键检查：
- 距离是否符合拳脚/武器有效范围；
- 攻击是否有起点、路径、接触、反馈；
- 防守是否真正改变攻击轨迹；
- 至少有一次主动权变化（若时长允许）；
- 场景锚点保持同一位置。

常见失败：一方木桩挨打、无接触后退、连续随机旋转、镜头绕得比人打得多。

## 2. Weapon Duel — 武器对决

目标：武器重量、长度、握法、攻防距离保持一致。

内部编排：试探/抢线 → 首次明确碰撞 → 改变角度/距离 → 一方失势 → 夺回或终结。

长兵器、短刀、双手重武器、枪械的空间逻辑不同，禁止套相同近身距离。

## 3. One vs Many — 一对多

目标：数量有压迫感，主要接触仍可读。

规则：
- 背景维持群体威胁；
- 同时真正接触的主要敌人数量保持可读；
- 通过进入/退出攻击圈、环境卡位、挑飞/撞开等建立波次；
- 被击倒/退出的敌人不无故回满；
- 主角不能360度无差别挥舞而所有人自动飞走。

## 4. Team Combo — 双人/团队连携

目标：动作互相创造条件。

常用因果类型：
- 牵制 → 绕后；
- 破防 → 重击；
- 挑起/推移 → 接杀；
- 格挡救援 → 反击；
- 控制视线/肢体 → 攻击弱点；
- 一人吸收Boss注意 → 另一人改变地形或完成任务。

禁止：A打一套、切B打一套、再切A，双方没有因果关系。

## 5. Boss Fight — 强敌/Boss

目标：Boss改变战局，不只是巨型沙袋。

推荐升级逻辑（按时长择取）：
1. Boss建立威胁：一次真正迫使主角改变动作的攻击；
2. 主角试探/普通攻击效果有限；
3. Boss第二种反制：抓取、冲撞、范围攻击、破坏场景、分割队伍等；
4. 主角通过观察/连携制造弱点；
5. 伤害阶段持续：失衡/破甲/关节受损/核心暴露；
6. 终结：路径清楚、接触即产生结果。

大型敌人的每一步应改变空间或压力，不要连续几秒原地转身挥臂。

## 6. High-VFX Fantasy — 高特效奇幻

目标：夸张但仍可读。

规则：
- 能力先绑定角色/武器；
- 每次爆发有动作来源；
- 粒子、闪光和能量拖尾不覆盖主体；
- 大招造成明确环境/身体结果；
- “瞬移”若是能力，需有视觉起点和落点；否则按连续位移处理。

## 7. Chase Combat — 追逐战

目标：追逐关系可追踪。

每个动作交换改变距离或路线：
- 近身 → 推开拉远；
- 阻挡 → 被迫换路；
- 抓住 → 短暂缠斗；
- 环境破坏 → 开辟/封死通道。

保持屏幕方向和目标位置，避免切镜后追的人突然跑到前面。

## 8. Entrance Beat — 重要角色登场

目标：高速中仍能认出角色。

结构：
1. 用明确行动介入当前冲突；
2. 给运动中可读身份的一拍；
3. 立即用下一动作交代关系。

身份信息优先：脸/轮廓、独特服装、武器、能力中至少两项清楚。避免角色从远景阴影里跳出来后立刻混入人群。

## 9. Finisher — 终结

结构：
机会 → 通道 → 接触 → 即时结果 → 结束状态。

避免：武器贴在目标身上持续几秒发光；闪白后不知道目标是否倒下；结束状态和上一秒伤势矛盾。

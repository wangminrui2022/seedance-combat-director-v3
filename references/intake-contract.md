# Intake Contract — 必要输入门槛

## 目标

保证 Agent 在编写 Seedance 打斗提示词前拿到足以决定结构的输入，避免“缺什么就自己猜什么”。

## 一级硬字段：必须明确

| 字段 | 合格示例 | 不合格示例 |
|---|---|---|
| 时长 | 15秒 / 30秒 | “短一点” |
| 画幅 | 16:9 / 9:16 | “视频比例正常就行” |
| 参战者 | @图1=A，@图2=B；或“允许你文字设计A/B” | 只说“打起来” |
| 战斗关系 | A vs B；A+B vs Boss | “做个大战” |
| 场景 | 地铁检修站；或“场景由你设计” | 完全缺失且未授权 |
| 战斗方式 | 徒手硬派；刀剑；魔法+近战；或“由你设计” | 完全缺失且未授权 |
| 节奏/摄影 | 高速硬切；一镜到底；ACT跟拍；或“由你设计” | 完全缺失且未授权 |
| 结局/目标 | A胜；击败Boss；逃脱；开放结尾；或“由你设计” | 完全缺失且未授权 |

“允许你设计”是有效输入，因为它明确给出创作授权；Agent 可以创作，但仍必须遵守已锁定的素材与关系。

## 二级条件字段

### 新生成
- 若用户要求精确保持某角色身份：必须有对应参考图/资产。
- 若角色可由文字设计：不强制上传资产。

### 修改成片
必须有：
1. 实际生成视频；
2. 用户希望重点修的问题，或授权 Agent 全面诊断；
3. 需要保留的成功部分（若用户已说明）。

不能只拿旧提示词推断成片问题。

### 续接
必须有：
1. 源视频或至少可读取的末段；
2. 从哪里接（默认从片尾也必须由用户或素材语境明确）；
3. 下一段的核心目标；
4. 需要继续锁定的人物资产。

### 参考视频节奏
必须实际可查看参考视频。看不到时，不说“已经分析节奏”。

## 一次性询问规则

不要每轮只问一个字段。将所有缺失硬字段一次性列出；用户回答后再次检查，只追问仍会改变结果的字段。

若用户说“其他都按你觉得好的来”，可把未指定的**创作型字段**视为授权，但时长和画幅仍需明确，除非当前生成入口本身明确固定且用户已知晓。

## 禁止行为

- 不默认30秒；
- 不默认16:9；
- 不默认24fps/4K；
- 不默认“全程高速硬切”；
- 不默认Boss；
- 不默认双人；
- 不默认武器/特效颜色；
- 不默认雨夜、寺庙、废墟等旧案例环境；
- 不因看见角色手持武器就擅自决定胜负和剧情；
- 不在信息缺失时先给“参考稿”。
